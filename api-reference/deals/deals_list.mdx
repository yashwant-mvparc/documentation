---
title: "List Deals"
description: "Fetch deals across pipelines with stage breakdown, filtering, and summary metrics."
api: "GET /deals"
---

### Query Parameters

<ParamField query="pipeline_id" type="string">
  Filter deals by specific pipeline UUID. If omitted, default pipeline is returned.
</ParamField>

<ParamField query="stage_id" type="string">
  Filter deals by a specific stage UUID.
</ParamField>

<ParamField query="owner_id" type="string">
  Filter deals by assigned team member UUID.
</ParamField>

<ParamField query="search" type="string">
  Search keyword in deal title, notes, or company name.
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `open`, `won`, or `lost`.
</ParamField>
