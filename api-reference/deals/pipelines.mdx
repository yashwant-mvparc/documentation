---
title: "Pipelines & Stages"
description: "Retrieve configured sales pipelines, stages, ordering, and default win probabilities."
api: "GET /pipelines"
---

### Query Parameters

<ParamField query="id" type="string">
  Optional: Pass a specific pipeline UUID to fetch only that pipeline.
</ParamField>
