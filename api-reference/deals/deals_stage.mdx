---
title: "Move Deal Stage"
description: "Progress a deal to a new stage in its sales pipeline, updating stage probability and transition history."
api: "PUT /deals/{id}/stage"
---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the deal.
</ParamField>

### Request Body

<ParamField body="stage_id" type="string" required>
  The UUID of the destination stage.
</ParamField>

<RequestExample>

```json Request
{
  "stage_id": "stage-negotiation-uuid"
}
```

</RequestExample>

<ResponseExample>

```json Response
{
  "success": true,
  "data": {
    "deal": {
      "id": "deal-9812-uuid",
      "title": "Global Tech Licensing",
      "stage_id": "stage-negotiation-uuid",
      "stage_changed_at": "2026-11-20T12:12:00.000Z",
      "status": "open"
    }
  }
}
```

</ResponseExample>
