---
title: "Mark Deal as Won"
description: "Close a deal as Won, recording final revenue, close timestamp, and updating CRM sales reports."
api: "POST /deals/{id}/won"
---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the deal to mark as won.
</ParamField>

### Request Body

<ParamField body="actual_revenue" type="number">
  The realized deal value if different from original expected amount.
</ParamField>

<ParamField body="notes" type="string">
  Closing notes or reason for win.
</ParamField>

<RequestExample>

```json Request
{
  "actual_revenue": 55000,
  "notes": "Contract signed and upfront payment completed."
}
```

</RequestExample>

<ResponseExample>

```json Response
{
  "success": true,
  "data": {
    "deal": {
      "id": "deal-9812-uuid",
      "title": "Global Tech Licensing",
      "status": "won",
      "won_at": "2026-11-20T12:15:00.000Z",
      "actual_revenue": 55000
    }
  }
}
```

</ResponseExample>
