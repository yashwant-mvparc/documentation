---
title: "Deal Activities"
description: "Retrieve activity history or record new calls, notes, and emails directly on a deal timeline."
api: "GET /deals/{id}/activities"
---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the deal.
</ParamField>

### POST Request Body (to record activity)

When adding an activity (`POST /deals/{id}/activities`):

<ParamField body="type" type="string" required>
  Type of activity: `note`, `call`, `email`, `meeting`, or `task`.
</ParamField>

<ParamField body="title" type="string" required>
  Summary or subject of the activity.
</ParamField>

<ParamField body="description" type="string">
  Detailed notes, meeting summary, or discussion points.
</ParamField>

<RequestExample>

```json POST /deals/{id}/activities
{
  "type": "call",
  "title": "Discovery Call with CTO",
  "description": "Reviewed security requirements and agreed on terms."
}
```

</RequestExample>
