---
title: "Create Pipeline"
description: "Create a new sales pipeline with custom stages, ordering, and default win probabilities."
api: "POST /pipelines"
---

### Request Body

<ParamField body="name" type="string" required>
  The name of the pipeline (e.g., `Enterprise Sales`, `Partnership Deals`).
</ParamField>

<ParamField body="stages" type="array">
  List of initial stages with name, position, and win probability (0 to 100).
</ParamField>

<RequestExample>

```json Request
{
  "name": "Outbound Enterprise Pipeline",
  "stages": [
    { "name": "Discovery", "probability": 20, "position": 0 },
    { "name": "Security Review", "probability": 50, "position": 1 },
    { "name": "Contract Legal", "probability": 80, "position": 2 }
  ]
}
```

</RequestExample>

<ResponseExample>

```json Response
{
  "success": true,
  "data": {
    "pipeline": {
      "id": "pipeline-2200-uuid",
      "name": "Outbound Enterprise Pipeline",
      "stages": [
        { "id": "stg-1", "name": "Discovery", "probability": 20, "position": 0 },
        { "id": "stg-2", "name": "Security Review", "probability": 50, "position": 1 },
        { "id": "stg-3", "name": "Contract Legal", "probability": 80, "position": 2 }
      ]
    }
  }
}
```

</ResponseExample>
